Free · about 30 minutes, once

Install Memory Garden

Step by step, for MaoMao's iPhone.

You're on an iPhone. If SideStore is already on this phone, jump to step 7: add Memory Garden. Otherwise the first part happens on the laptop.

What you need

  • The Windows laptop (64-bit Windows 10 or 11) and the iPhone's cable.
  • The iPhone on iOS 18 or newer, with a passcode set (Settings → Face ID & Passcode).
  • Wi-Fi on the phone. Mobile data isn't enough for SideStore.
  • An Apple ID for this phone (free). A separate one per phone is best: make one at account.apple.com, write the email and password down, and keep the phone it texts codes to nearby.
Part 1 · on the laptop

Put SideStore on the iPhone

SideStore is the free app that installs and refreshes Memory Garden. The laptop is only needed this once.

  1. Get the laptop ready

    Download the helper, open the zip, and double-click Setup-MemoryGarden. It installs Apple's iPhone driver (iTunes, from apple.com) and iloader, then brings you back here.

    ⬇ Download the laptop helper
    If Windows says “Windows protected your PC”, click More info → Run anyway. The helper only downloads from Apple and from iloader's official page.
    Rather do it by hand?

    1. Install iTunes from Apple's website (not the Microsoft Store version — Apple's includes the iPhone driver).
    2. Install iloader (official page: iloader.app).

  2. Plug in the iPhone

    Unlock the iPhone and plug it into the laptop. On the phone, tap Trust and enter the passcode.

  3. Install SideStore with iloader

    Open iloader from the Start menu, then:

    Sign in with the Apple ID → pick the iPhone → Install SideStore (Stable)

    The email is case-sensitive. If a code appears on a phone, type it into iloader. Wait for “done”, then unplug.

Now pick up the iPhone

Point the iPhone's camera at this code and tap the link. The rest happens on the phone.

Part 2 · on the iPhone

Switch it on and add Memory Garden

  1. Trust the app maker

    Settings → General → VPN & Device Management → Developer App → your Apple ID → Trust

    Then: Settings → Privacy & Security → (scroll to the bottom) Developer Mode → On

    The phone restarts. Afterwards tap Turn On and enter the passcode.

  2. Connect LocalDevVPN

    SideStore uses this small free app to install and refresh over Wi-Fi. Nothing leaves the phone.

    Get LocalDevVPN on the App Store

    Open it and tap Connect.

  3. Open SideStore once

    Sign in with the same Apple ID. Go to My Apps and tap the 7 DAYS button next to SideStore to refresh it. If it asks about a certificate, accept.

  4. Add Memory Garden

    Tap the button. SideStore opens and adds the Memory Garden source. Open it and tap Get.

    ＋ Add Memory Garden to SideStore
    The button didn't open SideStore?

    Copy the link, then in SideStore go to Sources → + , paste it and tap Add.

    Last resort: install the app file directly (you won't get one-tap updates this way).

    Source link: https://github.com/Mxhddd/Memory-App/releases/latest/download/sidestore-source.json

  5. Open Memory Garden

    Pick Midnight Den, type your name, and Allow notifications so reminders can reach you.

    Nice extras (2 minutes)
    • Home Screen widgets: touch and hold the Home Screen → Edit → Add Widget → Memory Garden. The Flashcard widget lets you answer cards without opening the app.
    • Control Center: swipe down from the top right → + → Add a Control → Memory Garden.
    • Lock Screen: today's trail appears there, and on the Dynamic Island while you study.
    • Siri: say “What's next in Memory Garden?”
After that

Keep it running

Every 7 days: a refresh

A free Apple ID signs apps for 7 days. SideStore renews them in the background while the phone is on Wi-Fi and LocalDevVPN is connected. Memory Garden shows the days left in Settings and reminds you 2 days before.

To refresh by hand: connect LocalDevVPN, open SideStore → My Apps → Refresh All.

If it ever runs out, the app just won't open until you refresh. Nothing is lost.

Updates

When a new version comes out, SideStore shows an Update button for Memory Garden. One tap, and your progress stays.

Free Apple ID limits

Up to 3 apps per phone at a time (SideStore counts as one), and 10 new app installs a week. Updates and refreshes don't count. So don't sideload other apps with this Apple ID on this phone.

If something's off

Troubleshooting

iloader doesn't see the iPhoneUnlock the phone, tap Trust, try another cable or USB port. Still nothing? Reinstall iTunes from apple.com and restart the laptop.
“Untrusted Developer” when opening an appDo step 4: Settings → General → VPN & Device Management → Trust.
No “Developer Mode” in SettingsIt appears after SideStore is installed. Restart the phone and look again under Privacy & Security.
SideStore can't install or refreshBe on Wi-Fi, open LocalDevVPN and tap Connect, then try again. Still failing? Plug into the laptop and run iloader again (it renews the pairing).
“Maximum number of apps”The free Apple ID allows 3 apps on this phone. Remove other sideloaded apps signed with it.
Memory Garden won't openIts 7 days ran out. Connect LocalDevVPN and tap Refresh All in SideStore. Your data is safe.
Notifications don't arriveiPhone Settings → Notifications → Memory Garden → Allow. In the app: Settings shows whether they're on.

Memory Garden is free and private: everything stays on the phone. It trains memory skills; it is not a medical device.
